# Elsevier version

Files:

- myna_elsevier.tex: elsarticle two-column source
- myna_elsevier.pdf: compiled 14-page PDF
- myna_elsevier.docx: editable Word manuscript (main text, tables, figures, appendix, references)
- body_main.tex, body_appendix.tex: body text used by the wrapper
- refs.bib: curated bibliography (no Laya/VegaML)
- figures/: local copies of every figure used by this paper

Build:

    tectonic -X compile myna_elsevier.tex
